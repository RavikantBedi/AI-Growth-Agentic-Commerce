# Frontend

React and Vite interface for the AI Merchant Growth & Agentic Checkout application.

The complete setup guide, environment reference, API links, verification commands, and production deployment checklist are in the repository [README](../README.md).

## Commands

```powershell
npm install
npm run dev       # development server on http://localhost:5173
npm run lint      # Oxlint
npm run build     # TypeScript check and production bundle
npm run preview   # preview the production bundle locally
```

The Vite development server proxies API requests to `http://127.0.0.1:8000`. Start the backend before using the buyer or merchant flows.
